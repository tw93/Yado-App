# Yado

[English](README.md) · [简体中文](README.zh-CN.md) · 繁體中文 · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Italiano](README.it.md)

**Yado** 的官方指南和意見回饋儲存庫，Yado 是在 Mac 上管理 iPhone 的原生 App，重複照片、大型影片和不用的 App 一次清掉，整理主畫面，傳檔案，備份留在自己的 Mac 上。

Yado 是付費 App，每一份購買都用在後續的開發和更新上，這個儲存庫放使用指南、問題和意見回饋，不包含 App 的原始碼。

### 開始使用

1. 從上面的官網下載 Yado，拖進「應用程式」後開啟。
2. 用傳輸線連上 iPhone，解鎖後在手機上點「信任」，之後想用 Wi-Fi 連，在 Yado 選單（分頁列最左邊那隻燕子）裡選「無線連線」。
3. 每個會更動手機的操作在購買前都能免費用兩次，查看、掃描、瀏覽備份和製作備份一直免費，買好後開啟設定，在「一般」裡點「Yado 授權」旁邊的「管理授權」，貼上 Dodo Payments 郵件裡的授權碼，再點「啟用 Yado」。

## 常見問題

### 有公開的 GitHub 儲存庫，是不是說明 Yado 開源？

不是，這個儲存庫只放文件和社群意見回饋，App 的原始碼不公開。

### Yado 多少錢？

$19 USD 買斷，支援 2 台 Mac，沒有訂閱，之後的更新都免費，購買 14 天內用付款信箱寫信到 [hi@yado.house](mailto:hi@yado.house) 可以全額退款。

### 刪照片會不會刪錯？

刪掉的照片會進 iPhone 的最近刪除，30 天內都能在手機上復原，清理時搬到 Mac 的照片要先核對存下的是完整原始檔才會從手機上刪除，重複照片預設每組留下最好的一張。

### 會連網嗎，會上傳什麼？

照片、檔案和備份都不會離開這台 Mac，連網只用來下載 App 分類表和 iOS 版本清單、核對授權、檢查更新，以及當機後你同意時傳送當機報告，手機裡裝了哪些 App 不會上傳，詳細內容請見[隱私權說明](https://yado.house/tw/privacy?utm_source=github.com&utm_medium=referral&utm_campaign=yado-app-readme)。

### 授權碼在哪，換新 Mac 怎麼辦？

授權碼由 Dodo Payments 寄到結帳時填的信箱，可以在收件匣和垃圾郵件匣裡搜尋 Dodo，還是找不到就用付款信箱或 Payment ID 寫信到 [hi@yado.house](mailto:hi@yado.house)，這些資料不要貼到公開 Issue 裡。一份授權能用在 2 台 Mac 上，兩個名額都占滿時，新 Mac 上會列出已啟用的兩台，解除綁定其中一台就能在新 Mac 上啟用，舊 Mac 不在手邊也可以。

### 哪個網站是官方的？

**yado.house** 是 Yado 唯一的官網，App Store 上的「Yado: Claude Code & Codex」是另一位開發者的 App，和這裡沒有關係。
